# 做事方法论：窄楔子起步 + 自建 claw 铺满

个人开发者阶段，**获客用窄楔子**（IM → Agent），**产品目标是沿「自建 claw」路径铺满完整 Agent Infra**。

纪律：**不做无关赛道**（不讲成 LangChain 竞品、不去做全行业客服大盘）；**自建 claw 栈内（A1–A6）要做全**。

| | 卖什么 | 卖给谁 |
|--|--------|--------|
| **Infra A1–A6** | 自建 claw 全栈能力（接入→模型记忆→工具沙箱→观测→编排→私有化部署） | 开发者、企业 IT |
| **场景 B｜SaaS** | 结果（微信里会干活的助手） | 最终用户 → 再切小 B |

内容、课、项目**共用同一套叙事**：

> **如何跑通自建 MeClaw → 微信里能干活的助手。**

若只能先押编码顺序：**先 A1（已通）→ A2 → … → A6**；场景 B 同仓后置。主路径见 [self-hosted-claw.md](./self-hosted-claw.md)。

## 整条链（每个环节干什么）

学习、项目、对外分析、知识付费、自媒体、To B、To C **不是并列清单**，是同一路径上的闭环。任一环节产出，都要能喂给下一环。

```text
        ┌─────────────── 信任与获客 ───────────────┐
        ▼                                           │
   学习踩坑 ──► 项目（可交付资产）──► 对外分析 ──► 自媒体
        │              │                  │           │
        │              │                  └─────► 知识付费
        │              │
        │              ├─► Infra A1–A6 开源 / 私有化（To B）
        │              └─► 场景 B 成品助手（To C → 小 B）
        │
        └────────────── 素材一律来自真实踩坑与交付 ──┘
```

| 环节 | 卖 / 产出什么 | 在飞轮里的职责 | 纪律 |
|------|---------------|----------------|------|
| **学习** | 踩坑、对照、可复述的结论 | 给内容与架构图供料；学习 ≠ 囤课 | 学当前关卡：IM↔Agent、模型/记忆、工具/沙箱、观测、部署 |
| **项目** | 可安装、可演示、可报价的资产 | 开源 Star + To B 交付物 + SaaS MVP | Agent 线只养 **1 个仓（meclaw）**；硬件仓可后接，不强绑 |
| **对外分析** | 深度文/视频（对比、坑、成本账） | 把踩坑变成可检索的信任证据 | 标题对准搜索意图；证据来自自己的项目，不抄综述 |
| **自媒体** | 持续在场（周更节奏） | 把分析拆薄、拉长触达；人设稳定 | 人设：自建 claw / Agent 基建实战 |
| **知识付费** | 可复制路径（小册/录播/内训） | 把「你会」变成「别人能照做」 | 卖「如何跑通自建 claw」，不卖空概念 |
| **To C** | 个人订阅 / 邀请制用量 | 验需求与定价 | 邀请制冷启动；不做开放注册烧 Token |
| **To B** | 私有化 / 席位 / 实施 | **主收入** | 客户要窄：研发效能、内部运维 Bot——不做客服大盘 |

### 三者必须同楔

| 载体 | 卖点 | 禁止跑偏 |
|------|------|----------|
| 知识付费 | 可复制「自建 claw」路径 | 讲成通用 Agent 平台课 |
| 自媒体 | 持续在场 | 人设周周换赛道 |
| 项目 | 可交付资产 | Infra 讲 LangChain 竞品、SaaS 去做全行业客服 |

## 飞轮怎么转

```text
学习踩坑 ──► 开源自建 claw（A1–A6）
                │
                ├─► 自媒体 / 分析（信任）──► 知识付费
                │
                └─► 同仓封装 SaaS（场景 B）
                        │
                        ├─► To C 订阅（验需求和定价）
                        └─► To B 私有化 / 席位（主收入）
```

执行节奏见 [飞轮与 90 天节奏](./playbook-flywheel-90d.md)。

## 每周自检

1. 本周产出是否仍落在「自建 claw / 微信里干活」？
2. 学习是否变成了可公开的踩坑素材？
3. 代码是否仍在 `meclaw` 单仓，能力是否挂在 A1–A6 地图上？
4. 对外一篇内容，能否同时服务 Star / 课 / 私有化询盘中的至少一环？
5. To C 是否仍在邀请制，没有提前烧 Token？
6. 是否在做「自营公有多租户云」这类明确不做的事？
