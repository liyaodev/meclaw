# Agent Infra + Agent SaaS（概念）

## Agent Infra（基础设施层）

给别人「造 Agent / 跑 Agent」用的底座，例如：

- 模型接入与路由
- 工具调用、记忆、编排
- 沙箱 / 浏览器 / 电脑操控
- 可观测、评测、权限与多租户

卖的是能力与平台，客户是开发者或要自建 Agent 的公司。

## Agent SaaS（应用层）

面向最终业务场景的成品 Agent 产品，例如客服、编程、销售、运维助手。用户直接用，按席位/用量订阅，不一定自己搭底层。

## 「Agent Infra + Agent SaaS」

通常指同一家公司（或同一战略）两边都做：底层平台 + 上层垂直产品。

- **Infra** 沉淀复用能力
- **SaaS** 拿场景和收入

也有人用这句话概括整条 Agent 价值链。

## 与 MeClaw 的关系

MeClaw 是这条价值链上的**单一开源仓库**（承接 WeClaw 级微信↔Agent 能力）：

- **场景 A（Infra）：** IM → Agent 接入与运行时（本仓库核心）——卖能力给开发者 / 企业 IT
- **场景 B（SaaS）：** 微信工作助手（同仓 `skills/` + 后期 `hosted/`）——卖结果给最终用户

两套场景是同一底座的上下层，不是两个产品线。做事方法论见 [methodology.md](./methodology.md)。

硬件互动线（抓娃娃 / 遥控车等）独立仓库；可后接「远程设备技能」，不强绑。
